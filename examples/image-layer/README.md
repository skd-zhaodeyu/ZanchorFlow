## 代表页面与编辑单位

![第 2 页：六字段内容架构](representative.png)

第 2 页包含 **30 个原生文字对象和 5 个图片对象**。六字段标题和说明文字可逐项修改，六叶书本插画等资产可独立选中与移动。

29 个图片对象包含 23 个模型前景、5 张背景和 1 个从批准原图恢复的字形资产。该字形保留原来的造型，作为图片对象编辑。插画的内部线条仍属于对应图片资产；部分图层移动后可见背景残影或边缘变化。
